# assets/

サイトで使う画像などを置く場所です。

## ロゴの差し替え

このフォルダに **`logo.png`** を置くと、トップのロゴが自動でその画像に切り替わります。
ファイルが無い間は、文字組み（タイポグラフィ）の「IDERIA」が表示されます。
差し替えをやめたいときは `logo.png` を削除するだけで、タイポ表示に戻ります。

- 推奨: 背景が透明なPNG／横長・高さ300px以上
- ダークとライトの両方で見えるか確認してください（ヘッダー右のボタンで切り替えられます）
- 別のファイル名にしたい場合は `data.js` の `site.logo` を変更します
