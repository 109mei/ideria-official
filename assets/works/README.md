# assets/works/

作品図鑑の図版を差し替える場所です。

## 差し替え方

1. `01.png`〜`07.png` のように **図鑑No.と同じ名前** で画像をこのフォルダに置く
2. `data.js` のその作品の `image` に `"assets/works/02.png"` と書く

これで、その作品のカードの図版が画像に切り替わります（`docs/SITE_SPEC.md` §3-3）。

- `image` が空の作品は、作品ごとに描き分けたオリジナル図版（SVG）が表示されます
- 画像が読み込めなかったときも自動でその図版に戻るので、カードが崩れることはありません
- 推奨: 横長（16:10 前後）／横幅600px以上
- 写真は `.jpg`、イラスト・ゲーム画面は `.png` が軽くなる（`data.js` の `image` に書いた拡張子がそのまま使われる）
